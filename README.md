# STAR DEPTH（仮）

スマホ縦持ち・タッチ操作専用の奥行きシューティング（ブラウザゲーム）。
描画は Canvas 2D の擬似3D（2Dスプライトの拡大縮小）で軽量に。

## 現在の状態：v2 プロトタイプ（1面＋ボス、機体ARROWのみ）
大改修中。方針は `docs/redesign-v2.md`、経緯は `docs/devlog.md`、1面の緩急グラフは `docs/pacing-stage1.png`。
- 弾は自機の位置から真っすぐ飛ぶ（敵の正面に入る＝撃てる＝狙われる）
- 長押し：照準に敵をとどめ続けると1つずつロック → 離して誘導レーザー（撃てる数はエネルギー制）
- ダブルタップ：宙返り（一瞬無敵）
- 旧版の機体選択・パーツ・勲章・日替わりは凍結中（`src/ships.js` `src/parts.js` などはファイルだけ残している）

## 遊び方（旧版の説明）
- 画面下の操作エリアをドラッグ：自機移動（ショットは自動）
- 長押し：ロックオン → 指を離すとホーミングレーザー一斉発射（まとめて倒すほど高倍率）
- 全6ステージ。ゲームオーバー時はそのステージからコンティニュー可（スコアは0から）
- ダブルタップ：宙返り（一瞬無敵、再使用まで約1秒）
- ランク：時間経過と大量ロックで上昇（ステージごとに上限あり）、被弾で低下
- HARD（6面到達で解放）：後方から追い抜いてくる伏兵、撃破時の撃ち返し弾、ボスの追加攻撃と瀕死時の激化。得点1.3倍
- DAILY：日付で決まる機体・ステージ・ルール2つの1ステージ勝負
- BGM：Web Audio でその場で合成（ステージごと・ボス・タイトル）。タイトルで BGM/SE の ON/OFF
- オフライン：一度開けば圏外でも遊べる（Service Worker、常にネット優先で最新を取得）

## やり込み要素
- **勲章 24種**：各ステージ3つ（ノーダメージ／ステージ固有の課題／撃墜率90%）＋全体6つ。パーツなしで取ると金色（PURE）
- **カスタムパーツ 13種**（2スロット、勲章12個で3スロット目）：攻撃・防御・技巧・サポートの4系統。解放は「勲章の数」か「出撃回数」
- **隠しコンボ 5種**：特定の2パーツをそろえると名前付きの相乗効果（例：CHARGE LOCK＋SPLIT LASER＝PRISM）
- **サポートパーツ**（AUTO GUARD／SLOW FIELD／AUTO LOCK）：付けるとクリアが目に見えて楽になる。クリア記録は残るが、勲章・ハイスコアは対象外。2連敗するとおすすめを表示
- 途中ステージから開始可能（到達済みのステージ）。勲章は取れるが、ハイスコアとALL CLEARは1面開始のみ
- 企画の経緯は `docs/design-proposals.md` / `docs/design-decision.md`、開発記録は `docs/devlog.md`

## 動作環境
- iOS Safari / Android Chrome（最近のバージョン）
- 画面は 9:16。縦長端末では下に操作用の帯、横長端末では左右に帯

## ローカル実行
ES Modules を使うため、ファイル直開きではなく簡易サーバーで開く：
```
npx serve .    または    python -m http.server
```

## デバッグ用URLパラメータ
- `?t=100` … ステージの途中（秒）から開始
- `?god` … 無敵
- `?bot` … 自動操縦（動作確認用）
- `?auto` … タイトルを飛ばして即開始
- `?stage=3` … 指定ステージから開始（`?t=999` と組み合わせるとボス戦から）
- `?ship=0〜4` … 機体を指定
- `?speed=4` … 早送り（自動テスト用）
- `?hard` … HARD / `?parts=charge.split` … パーツ指定 / `?roll` … ボットが宙返りも使う
- ※デバッグ用パラメータ付きのプレイは勲章・記録が保存されない
