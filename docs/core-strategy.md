# ARROW の基本戦略：ショットで稼いで、ロックで打開する

## きっかけ
v2 を遊んだユーザーの指摘：「通常ショットで攻撃したいときも、ロックオンしたいときも敵の正面に立つ。操作が同じなので使い分けられない」。
操作をいじる前に、**プレイヤーが自発的に考える基本戦略**（ゲームが与えるミッションではない）を先に言語化し、それを操作の意図に落とすことにした。

## 基本戦略（一言）
普段はショットで正面の敵を1体ずつ処理して場を保つ。処理が追いつかなくなった瞬間に、ロックオンで一気に片付けて主導権を取り戻す。

## メインはショット
- 撃ち続けてもコストはかからない
- 代償：敵の正面（＝狙われる位置）に入る必要があり、1度に1体しか削れない
- プレイヤーが考えること：「どの敵の正面に、いつ入るか」

## ロックオンは「打開」の切り札
ショットでは解決できない3つの状況で使う。
1. **数に押される**：1体ずつでは間に合わない → まとめて消して場をリセット
2. **正面に入れない**：正面が弾幕・機雷で危ない、画面の端にいる → 行かずに届ける
3. **時間がない**：撃つ直前の敵、突っ込んでくる敵 → すぐに大ダメージ

エネルギーには限りがあるので「今使うか、もっと危ない場面まで取っておくか」を自分で判断する。
引きつけて多く巻き込むほど得点倍率が上がる＝欲張るほど危険、という駆け引きも乗る。

## v2 とのズレ（直したこと）
| v2 | 問題 | v3 |
|---|---|---|
| 指を置いて動いているだけでロックが溜まる | 「使う」と決める瞬間がない | **ダブルタップで発動**（使うと決めた瞬間だけ） |
| ロックは照準（正面）の中だけ | ショットと同じ位置取りになる | **自機から輪が広がり画面を掃く**。近い敵から順にロック |
| エネルギーが1.4秒で1回復 | 取っておく意味が薄い | **時間では回復しない**。ショットで倒すと+1（硬い敵は+2）、リングで+2 |
| ショットとロックが別の資源 | 2つがつながっていない | **ショットで稼いで、ロックで使う** |

## 操作（v3）
- ドラッグ：移動（ショットは自動で正面へ）
- ダブルタップ：エネルギーがあればロックの輪 → 一斉発射（0なら発動しない）
  - 宙返り（一瞬無敵）は外した。回避は位置取りだけで行う。宙返りは別の機体の個性に回す（ユーザー判断）
- 輪は近い敵から順にロックするので、**どこで発動するか**（敵の群れに近づいてから押す）が位置取りの判断になる

## 敵とステージの合わせ込み
- **砲撃機は自分の正面に撃つ**（光っている間、自機の面に赤い円で射線を予告）：「正面に入る＝狙われる」を文字どおりにした。ショットで正面から削るなら、光る前に
- 1面に打開の3場面を順に配置：
  1. 交戦区間の終わりに偵察機14体の群れ（数に押される）→「多すぎる！ ダブルタップ」
  2. 狙撃機の正面を機雷がふさぐ（正面に入れない）
  3. 危険区間の突撃機（時間がない）、ボスの排熱3秒（取っておいたエネルギーをコアへ）
- その前後にショットで稼げる雑魚を置く。ボスも偵察機を呼び続ける（稼ぎ場）
- 装甲巡洋艦の耐久 110→120、砲台 20→16（エネルギーが貴重になった分、砲台は早く壊せるように。宙返りでエネルギーを漏らさなくなった分、本体は少し硬く）
