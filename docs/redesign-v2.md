# STAR DEPTH 大改修案（v2）

## 0. 指摘の整理：根本原因は「自機が強すぎて、敵に考える余地がない」

| ユーザーの指摘 | 根本原因 |
|---|---|
| 反射的に頭を使わない／避けながら狙う遊びがない | ロックオンが「範囲に入れて離すだけ」で、狙う行為がほぼ不要。自動ショットにもエイムアシストがある |
| 敵を瞬殺して個性を認識できない | 敵の耐久とレーザー威力が釣り合っていない。敵の「予兆（何をしてくるか）」の表現がない |
| 単調／緩急がない | 出現→撃破を均一な密度で繰り返している。地形・障害物などの「戦闘以外の局面」がない |
| ボスが似ている | 共通の攻撃部品（扇・リング等）の組み合わせを変えただけ。「そのボスでしか起きない遊び」がない |
| 長い | 6面×約2分＋ボス。1面あたりの密度に対して長すぎる |
| 機体差が意識しづらい | 全機体が「移動＋自動ショット＋ロックオン」の数値違い |

方針：**「操作の動詞」を機体ごとに変え、敵には「読める予兆」と「倒し方の正解」を持たせ、ステージには「緩急の設計図」を引く。**
4ステージ・1面約2分（道中75秒＋ボス45秒）・全体約9分。

## 1. コアループの作り直し

### 1-0. 設計の大原則（ユーザー指示）
**シューティングの面白さは「自機の位置取りが、攻撃と回避を兼ねていること」。基本機体はこれを最優先にする。**（別の機体ではこのルールを破ってもよい）
- 攻撃は自機の位置から真っすぐ前（奥）へ。狙う＝その敵の正面に入ること
- 敵の攻撃も自機の位置を狙ってくる。正面に入るほど危ない → 「どこに居れば撃てて、かつ避けられるか」を常に考える
- 敵側にも位置取りの理由を作る：正面に強い砲を持つ敵（斜めから撃つと安全）、側面に弱点がある敵、自機の軸線をなぞってくる攻撃など

### 1-1. 「狙う」を復活させる
- 自動ショットのエイムアシストを廃止。弾は機首の向き（=移動方向に少し傾く）にまっすぐ飛ぶ
- ロックオンは「範囲に入れたら即」ではなく、**照準の中に一定時間とどめると1つロック**（小型0.2秒、中型0.5秒）。照準から外れるとロック解除
  - → 敵の弾を避けつつ、照準を敵に合わせ続ける「避けながら狙う」が生まれる
- 一斉発射は**エネルギー制**（ゲージ1本でロック数ぶん消費、撃たないと回復）。連発で全滅、はできない

### 1-2. 殲滅力を下げつつ、爽快感は「連鎖」で出す
- レーザー1本の威力を下げる（小型は1本で倒れる、中型は2〜3本、大型は弱点が開いたときだけ有効）
- 代わりに**誘爆**を入れる：敵の種類によって、倒すと周囲を巻き込む爆発を起こす（爆雷艇、燃料タンク付きの輸送機など）
  - 「どれを先に撃てば一網打尽にできるか」を考える遊び＝倒す順番。うまくいけば一瞬で全滅して気持ちいい
- 大型敵は**弱点が開く瞬間**（攻撃の直前・直後）にだけ大ダメージ。その瞬間に溜めたロックを叩き込むのが爽快ポイント

### 1-3. 敵に「予兆」と「役割」を持たせる
すべての攻撃に0.5〜1秒の予兆（発光・照準線・効果音）を付け、見てから反応できるようにする。

| 敵 | 役割 | 予兆／対処 | 優先度の判断 |
|---|---|---|---|
| スカウト | 編隊で飛ぶだけ | ─ | 雑魚。ロックのエサ |
| スナイパー | 自機を狙って高速弾 | 赤い照準線が0.8秒出てから撃つ | 照準線を見たら横移動 |
| 盾持ち | 前面が無敵。周囲の味方を守る | 盾の向き | 回り込むか、盾を開く瞬間を待つ |
| 爆雷艇 | 倒すと周囲を誘爆。近くで倒すと自機も巻き込まれる | 点滅 | 敵の群れに近いうちに撃つと得 |
| 突撃機 | 一瞬止まってから突っ込む | 停止＋光る | 停止中に倒すか、宙返りで避ける |
| 母艦（中型） | 小型を射出し続ける | 射出口が開く | 先に倒さないとジリ貧 |
| 機雷 | 動かない。近づくと全方位に破裂 | 接近で点滅 | 遠くから撃つ／避けて通る |

## 2. ステージ：緩急の「設計図」を引く

各ステージを**区間**で組み立てる。区間ごとに「緊張度」を決め、交互に並べる。

| 区間 | 緊張度 | 中身 |
|---|---|---|
| 導入 | 低 | 景色・リング（くぐるとエネルギー回復と得点）・少数の雑魚 |
| 交戦 | 中 | 役割の違う敵の混成。順番を考える |
| 危険区間 | 高 | 画面が赤み、BGMが激しくなる。地形ギミック＋弾幕。15〜20秒で終わる |
| 休憩 | 低 | リング・アイテム。息をつく |
| ボス | 高 | ─ |

### 地形・ギミック（戦闘以外の局面）
- **ゲート**：穴の空いた壁が迫ってくる。穴の位置へ移動してくぐる
- **レーザー柵**：回転・横移動するビームの柵。タイミングを見て抜ける
- **隕石の狭路**：大隕石の隙間を縫う
- **霧**：見通しが悪く、敵が近づくまで見えない（レーダーの点だけ見える）

### 4ステージの個性
1. **外縁軌道**：基本の敵と「予兆」に慣れる。危険区間＝戦艦の横を通過しながら砲台の弾幕
2. **小惑星帯**：地形の面。狭路とゲートを抜けながら戦う。危険区間＝崩れる小惑星の雨
3. **星雲**：霧の面。見えない敵をレーダーで読む。危険区間＝霧の中から一斉に現れる群れ
4. **要塞**：レーザー柵と砲台の総決算

## 3. ボス：1体ずつ「そのボスでしか起きない遊び」を

| ボス | コンセプト | 遊び |
|---|---|---|
| 1. 装甲巡洋艦 | **部位破壊と順番** | 本体は無敵。4つの砲台を壊すと装甲が開く。主砲（画面を横切る極太ビーム）は予兆で安全地帯が見える。主砲を撃った直後だけコアが無防備 |
| 2. 採掘プラットフォーム | **地形を使う** | 自分では撃たず、小惑星を引き寄せて投げてくる。投げる前の小惑星を撃つと砕けて弾になる／放置すると巨大な塊が来る。どちらを選ぶか |
| 3. 群体マザー | **群れの制御（マルチロックの見せ場）** | 本体は群れに守られて無敵。群れが本体の周りで隊形（輪→槍→壁）を変えて襲ってくる。群れを一斉発射で一気に削ると、数秒だけ本体が露出 |
| 4. 双子の要塞核 | **2体の連携** | 2体の間にビームの綱が張られ、綱自体が画面を掃く。片方を倒すともう片方が暴走（もう一方の攻撃を引き継ぐ）。同時に削るか、片方ずつ確実にか |

共通部品（扇弾など）は使ってよいが、**各ボスの主役はその固有ギミック**にする。

## 4. 機体：操作の「動詞」から変える（4機体）

全機体共通：ドラッグで移動、ダブルタップで宙返り。**長押し〜離す**の意味が機体ごとに違う。

| 機体 | 長押し→離す | 通常攻撃 | 遊びの芯 |
|---|---|---|---|
| **ARROW**（標準） | 照準にとどめてロック → 離して誘導レーザー | 弱い連射 | 避けながら照準を合わせ続ける |
| **AEGIS**（吸収） | 前面にバリア展開。**敵弾を吸収**してエネルギー化 → 離すと吸収量に応じた反撃ビーム | なし | 弾を避けるのではなく**取りに行く**。バリアは熱を持ち、張りっぱなしはできない |
| **LANCER**（突撃） | 溜めて離すと、照準方向へ**体当たり突進**（突進中は無敵、通過した敵を貫く） | 弱い単発 | 敵の列と弾の隙間を一直線に貫くルートを読む |
| **SPECTER**（狙撃） | 溜めるほど照準が細く遠くまで伸びる → 離すと**奥行き方向に一直線の貫通弾** | なし | 敵を一直線に並ぶ瞬間まで待つ。1発で何体抜けるか |

- 機体ごとに得意なボス・苦手なボスがある（例：AEGIS は弾の多い3面が得意、SPECTER は群れの3面が苦手で1面ボスの部位破壊が得意）
- これまでの5機体（数値違い）は廃止

## 5. 既存のやり込み要素の扱い
- **勲章**：新しいステージ・ボスに合わせて作り直す（例：巡洋艦の砲台を順番どおりに壊す、AEGISで弾を100発吸収）
- **カスタムパーツ**：旧ロックオン前提の設計なので**いったん凍結**。新しいコアが面白くなってから、機体の動詞を伸ばす形で作り直す
- **サポート（救済）・日替わり・HARD・BGM・宙返り**：残す（HARDは新しい敵とボスに合わせて調整）

## 6. 進め方の提案：縦切りで先に「面白いか」を確かめる
前回は一気に広げてから遊んでもらい、根本でつまずいた。今回は**小さく作って遊んでもらう**順番にする。

1. **第1弾（縦切り）**：1面だけ（区間構成・新しい敵・装甲巡洋艦）＋ARROW と AEGIS の2機体 → 遊んでもらう
2. 感想をもとにコアを調整
3. **第2弾**：残り3面・3ボス・残り2機体
4. **第3弾**：勲章の作り直し、HARD・救済の調整、パーツの再設計

検証では、自動操縦で「区間ごとの敵弾の量」「被弾数」「敵1体を倒すまでの時間」を計測し、**緩急のグラフ**を作って設計図どおりになっているか確認する。

## 付録：機体案の候補一覧（ユーザーが「別の案も見たい」→ この中から4つ選ぶ）

条件：片手のタッチ操作（ドラッグ＝移動、長押し→離す、ダブルタップ＝宙返り）に収まり、**「何をする機体か」が一言で違う**こと。

| # | 機体 | 長押し→離す | 遊びの芯（一言） | 位置取り＝攻撃＋回避 |
|---|---|---|---|---|
| 1 | ARROW（標準） | 照準にとどめてロック → 誘導レーザー | 避けながら狙い続ける | 守る（基本機体の候補） |
| 2 | AEGIS（吸収） | バリアで敵弾を吸収 → 吸った分の反撃ビーム | 弾を取りに行く | 破る：弾に自分から当たりに行く |
| 3 | LANCER（突撃） | 溜めて照準方向へ無敵の突進 | 隙間を一直線に貫く | 守る（突進ルートが攻撃と回避を兼ねる） |
| 4 | SPECTER（狙撃） | 溜めて奥行き方向に一直線の貫通弾 | 敵が一列に並ぶ瞬間を待つ | 守る（並ぶ位置を探す） |
| 5 | TETHER（捕獲） | 照準の敵にワイヤーを刺して捕まえる → 離すと投げつける | 敵を武器にする（投げた敵が他の敵や弾を巻き込む） | 半分：投げる向きで決まる |
| 6 | WARDEN（設置） | 照準の位置に砲台ドローンを置く（最大3基）。自分は撃たない | 配置で戦う。どこに置けば敵の通り道を押さえられるか | 破る：攻撃は置いた砲台任せ |
| 7 | MIRAGE（欺瞞） | その場に分身を残す → 離すと分身と位置が入れ替わる。敵は分身も狙う | 避けるのではなく欺く | 破る：分身で回避 |
| 8 | GRAVITY（重力） | 照準の先に重力井戸。敵と敵弾を吸い寄せる → 離すと爆縮 | 敵も弾もまとめて一点に集めて潰す | 半分：井戸の位置が攻撃、自機は別の場所でもよい |
| 9 | CHRONO（時間） | 時間がゆっくりになり、その間に指でなぞった敵に印 → 離した瞬間まとめて一閃 | 止まった時間の中で順番を決める | 破る：時間を止めて選ぶ |
| 10 | PULSE（リズム） | BGMの拍に合わせて離すと衝撃波。拍に合うほど強い | 音に乗って戦う | 破る：タイミングが主役 |
