## 2026-09-30 準備フェーズ

### 決定事項
- ゲーム：スターフォックス風の奥行きシューティング。描画は2Dスプライトの擬似3D（Canvas 2D、素のJS、ビルドなし）
- 端末：iPhone / Android 両対応、タッチのみ、縦持ち。画面は9:16固定。縦長端末は下に帯（操作エリアとして活用）、横長端末は左右に帯
- ブラウザ：全ブラウザ共通が目標。機種依存が必要ならChrome優先
- 振動：一切なし（ユーザー判断：びっくりするため）。手応えは画面揺れ・フラッシュ・効果音で表現
- iPhoneの全画面：「ホーム画面に追加」（PWA）で対応
- 音：最初のタップ（TAP TO START）で有効化
- 古い端末はサポート対象外

### 環境・運用
- 作業フォルダ：J:\project\testproj2（ローカルgitリポジトリ、ブランチmain）
- gitコマンドはユーザーが実行（Claudeの環境からはWindows上でコマンド実行不可）。pushもユーザー
- 改行コードの差分対策：リポジトリ単位で core.autocrlf=false ＋ .gitattributes（eol=lf）
- クラウド環境から素材サイト（kenney.nl, GitHub等）へは接続不可 → ユーザーが手動DLして _src_assets/ に配置（gitignore対象）
- Proプラン配慮：サブエージェント並列を避け、スクリーンショット確認は最小限。サブエージェントは用途に合った性能・価格のモデルを選ぶ（ユーザー指示）

### 素材
- Kenney: Space Shooter Remastered / Space Shooter Extension / Sci-fi Sounds（すべてCC0、同梱License.txtで確認）

## 2026-09-30 夜間作業（ユーザー就寝中・自律作業）

## 2026-10-01 追加：自機5種・全6ステージ（ユーザー就寝中・自律作業）

ユーザー指示：「自機5パターン・6ステージ構成。面白ければなんでもいい、レビュー等は任せる」

### 自機（性能の差で遊び方が変わるよう設計）
- ARROW：バランス型（2連ショット・8ロック）
- LANCER：高速・貫通弾・6ロック高威力
- BULWARK：重装甲150・3WAY（初心者向け）
- SEEKER：最大12ロック・広範囲ロック（稼ぎ特化）
- PHANTOM：シールド60・極小当たり判定（判定点を表示）・スコア1.5倍（上級者向け）
- 機体選択画面（ステータスバー5段階・機体別ハイスコア）

### ステージ（背景テーマ・敵構成・ボスを全て変える）
1. OUTER ORBIT ─ BATTLE CRUISER（基本）
2. ASTEROID BELT ─ MINING RIG（隕石地帯、弾の雨）
3. CRIMSON NEBULA ─ MOTHER SAUCER（星雲の霧、UFO群、渦巻き弾）
4. FLEET LINE ─ TWIN LANCERS（2体同時ボス、弾の壁）
5. ORBITAL STATION ─ ORBITAL FORTRESS（追尾ミサイル、突進機）
6. THE CORE ─ THE CORE（3段階、全パターン）
- 新しい敵：追尾ミサイル、突進機、狙撃機、重装機、UFO群、ボーナスUFO、大型ロケット
- ボス攻撃8種：扇・リング・連射・子機・渦巻き・弾の雨・抜け穴1つの弾の壁・追尾ミサイル
- コンティニュー（そのステージから、スコア0）、ALL CLEAR画面（ノーコンティニュー判定）
- ステージクリアボーナス（残シールド＋ノーダメージ）

### 検証
- 全6ボス戦をそれぞれ別機体で起動してスクショ確認
- 早送りパラメータ（?speed=）を追加し、無敵ボットで1〜6面を通しクリア → ALL CLEAR まで動作確認
- 5機体それぞれで無敵なしのボットを並列に走らせ、到達面と被弾数を比較（素朴なボットで2〜4面到達）
- **Sonnetサブエージェントのレビューを1回**：最終ボスが攻撃をほぼしない不具合、隕石・ミサイルが出現直後に消える不具合、雲描画の負荷、死亡と同時にボス撃破した場合の進行不整合 → 全件修正

### ボットのデータから行った調整
- 無敵ボットが2面でランク最大に到達 → ランクにステージ別の上限（1面3 → 6面9.99）を設け、上昇速度も抑えた
- ボスを一斉発射で倒すとスコアが桁違い（SEEKER/PHANTOMが有利すぎ）→ ボスは一斉発射倍率の対象外に
- 2面ボスの弾の雨で多くの機体が撃墜 → 弾数を少し減らした

## 2026-10-01 やり込み要素・HARD・BGM・オフライン

ユーザー指示：「スコア以外に上級者が極めたくなる要素を。複数案をプレイヤー想定のエージェントにレビューさせて採用。未実装候補もできるところまで。体験を先鋭化ではなく増やす方向。HARDは自機弱体化でなく敵の行動パターン追加。初心者救済はあってよいが上級者の達成条件は満たさないように」

### 企画の進め方（プレゼン向けポイント）
- 5案（勲章／カスタムパーツ／S〜D評価／日替わり／経験値）を作成 → `design-proposals.md`
- **3ペルソナのサブエージェント（Sonnet）を並列で走らせてレビュー**：通勤中の初心者／STG歴20年のコア／ビルド研究・収集好き
- 評価が割れた案（経験値：初心者7点・コア2点）は「出撃回数でのパーツ解放」だけ取り込む、など折衷で採用 → `design-decision.md`
- 初心者ペルソナの「救済を使うとズル扱いされるのは嫌」を受けて、サポート出撃でもクリア記録は残し、表示も柔らかい言い回しに
- コアペルソナの「パーツなしの達成と区別したい」を受けて、パーツなし獲得の勲章は金色（PURE）に

### 実装したもの
- 勲章24種（各面3つ＋全体6つ）、記録画面（勲章・隠しコンボ図鑑・機体別クリア/1CC/HARD/ハイスコア）
- カスタムパーツ13種（攻撃・防御・技巧・サポート）、スロット2→勲章12個で3、解放は勲章数か出撃回数
- 隠しコンボ5種：PRISM／PHASE DANCER／COUNTER／TWIN CANNON／SALVAGER
- サポートパーツ3種（被ダメ半減／敵弾スロー／オートロック）：勲章・ハイスコア対象外、クリア記録は残る。2連敗でワンタップ装着のおすすめ
- 宙返り（ダブルタップで一瞬無敵）
- HARD：後方から追い抜く伏兵、撃ち返し弾、小型機も最初から射撃、ボスごとの追加攻撃（狙撃・十字弾ほか）、瀕死で攻撃激化、得点1.3倍
- DAILY：日付シードで機体・ステージ・ルール2つを決める1ステージ勝負
- 途中ステージからの開始（到達済みのみ）
- 合成BGM（Web Audioでベース・アルペジオ・ドラムをその場で生成。ステージ別6曲＋ボス＋タイトル）、BGM/SEのON/OFF
- オフライン対応（Service Worker、ネット優先で常に最新）

### 検証
- ボットで各パーツ・コンボ・HARD・全ボスを起動してエラーなしを確認、メニュー画面を自動タップで巡回
- 同じ機体（ARROW）で比較：素のまま→4面で撃墜、サポート2つ→6面到達（救済が目に見えて効くことを数値で確認）
- 無敵ボットでHARD全6面を通しクリア
- **Sonnetサブエージェントのレビュー**：7件指摘 → 全件修正。例：LONG ROLLの連打で常時無敵になりノーダメージ勲章がタダ取り／サポート装着でもコンボ勲章が取れる／デバッグ用URLで勲章が取れる／Service Workerがブラウザキャッシュ経由で新旧ファイルを混在させうる
